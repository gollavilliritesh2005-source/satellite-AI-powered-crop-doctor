# 🛰️ Satellite AI-Powered Crop Doctor

An end-to-end precision agriculture web app that analyzes multispectral satellite imagery (Sentinel-2 bands) to assess crop biomass, moisture, and generate automated diagnostic prescriptions.

## 🚀 Features
- **Multispectral Satellite Analysis:** Computes NDVI and NDWI vegetation maps.
- **Stress Identification:** Pinpoints disease and water deficit hot-spots.
- **AI Prescription Engine:** Delivers targeted fertilizer and irrigation recommendations.

## 🛠️ How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Launch Streamlit UI: `streamlit run app.py`
